# iiod-rs

A userspace Rust implementation of the Linux Industrial I/O wire protocol for controlling AD936x-based SDRs (e.x. PlutoSDR, FMCOMMS2/3/4/5, ADRV9361/9364, Oxygen SDR, etc.) running the `iiod` daemon, without depending on `libiio` or other drivers installed, over Ethernet, USB, serial, etc.
